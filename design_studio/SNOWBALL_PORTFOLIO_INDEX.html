Deployment Guide — Go Live in 60 Seconds
01
Netlify Drop (Fastest)
Go to netlify.com/drop, drag any HTML file onto the page. Live URL in under 30 seconds. Free forever on the free tier.
netlify.com/drop
02
Vercel (Best Performance)
Install Vercel CLI, run the deploy command. Global CDN, automatic HTTPS, custom domain support. Free tier is more than enough.
vercel deploy [filename].html
03
GitHub Pages (Free Forever)
Push to a GitHub repo, enable Pages in settings. Rename your chosen file to index.html first. yourname.github.io/snowball is your URL.
github.com → Settings → Pages
